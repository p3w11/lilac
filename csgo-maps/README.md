# CS:GO MAPS — каталог карт

Сайт без базы данных. Сканирует свою папку, показывает все `.bsp` /
`.bsp.zst` списком с поиском и кнопкой «Скачать». Файлы кладёшь сам —
через файловый менеджер хостинга или FTP.

## Как пользоваться

1. Кладёшь `.bsp` в папку проекта (там же лежит `index.php`).
2. Открываешь страницу. Карта уже в списке.
3. Удалил файл — пропала из списка.

## Адрес на хостинге

Если на хостинге папка проекта лежит как `htdocs/csgo/maps/`,
то каталог открывается по адресу:

```
http://домен/csgo/maps/
```

## Файлы

| Файл | Зачем |
|---|---|
| `index.php` | вся страница: список, поиск, сортировка |
| `assets/style.css` | оформление |
| `assets/app.js` | живой фильтр при вводе, копирование команды |
| `.htaccess` | отключает листинг директории, кэш статики |
| `serve.cmd` | локальный запуск через `php -S` |

## Что показывает каталог

- Название карты (из имени файла, `_` заменяется на пробел).
- Размер и дата изменения.
- MD5, если рядом лежит файл `карта.bsp.md5` — Valve так кладут
  хеши для проверки.
- Кнопку `map <имя>` — копирует команду в буфер обмена.
- Ссылку на Workshop, если имя файла начинается с ID
  (`3083967655_arcanum.bsp`).

## Сортировка

По названию, размеру и дате — переключается ссылками, состояние
сохраняется в адресе (`?sort=size`). Поиск тоже в адресе (`?q=`),
поэтому ссылку можно скинуть другу.

## Ограничения

- Лимит на размер одного файла задаёт хостинг. На InfinityFree это
  примерно 5 МБ. Карты больше не зальются — виноват не код.
- Каталог показывает максимум 2000 файлов (`MAPS_LIMIT` в `index.php`).
  Если карт больше, остальные не попадут в список.
- Лимит запросов хостинга тоже считается: страница делает один запрос
  при открытии и фильтрует на клиенте, а не перезапрашивает сервер.
