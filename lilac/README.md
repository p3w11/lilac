# 💜 Lilac

Небольшой чат для своих: регистрация, вход, общий чат и личные переписки.
Работает на чистом Node.js, без базы данных — данные лежат в одном файле `data/db.json`.

## Что умеет

- Регистрация по логину и паролю (пароли хранятся в виде хэшей bcrypt)
- Вход / выход, сессия в httpOnly-куке на 30 дней
- **Общий чат** — где все
- **Личные переписки** 1-на-1 (кнопка «+ Написать друга», поиск по логину)
- Доставка в реальном времени через WebSocket, «печатает...», список тех, кто онлайн
- **Отметки о прочтении** — «прочитано» у твоих сообщений
- Счётчики непрочитанных, разделители дат, автопрокрутка
- Адаптив под телефон
- **Группы и каналы**: создание, участники, помощники, публичные каналы
- **Голосовые звонки** один на один в личных переписках: микрофон, mute, сброс
- **Демонстрация экрана** во время звонка: весь экран, окно или вкладка
- **Звуки**: уведомление о сообщении, гудок входящего звонка, отключаются кнопкой 🔔
- **Профиль**: аватар, своё отображаемое имя, описание «о себе», смена пароля
- **Настройки приватности** — 5 переключателей, как в Telegram/Discord
- **Роли**: участник / модератор / админ, выдаются из админки
- **Админка**: статистика, роли, удаление пользователей и сообщений, очистка чата
- Необязательный **код приглашения**, чтобы посторонние не регистрировались

## Звуки

Колокольчик 🔔 в шапке чата — кнопка звуков. Выбор запоминается в браузере.

| Звук                        | Когда                                            |
| --------------------------- | ------------------------------------------------ |
| короткий перелив           ### Диагностика
| тихий щелчок                | ты отправил своё сообщение                        |
| гудок, как у телефона      | входящий звонок, повторяется каждые 10 секунд     |
| вибрация                  | входящий звонок на телефоне                        |
| короткий аккорд вверх       | соединение состоялось                            |
| нисходящий сигнал           | вызов отклонили или звонок сбросили               |

Файлов со звуками в проекте нет — сигналы собираются прямо в браузере через
Web Audio. Поэтому ничего не грузится и звук не зависит от интернета.

Браузеры не дают проигрывать звук, пока пользователь не кликнул по странице, поэтому
звук появляется после первого нажатия. Если раздражает — выключи колокольчик.

## Профиль

Кнопка **«Профиль»** внизу боковой панели. Меняются:
- аватар (PNG, JPEG, WebP или GIF, до 400 КБ)
- отображаемое имя (до 32 символов)
- описание «о себе» (до 200 символов)
- пароль (нужен текущий)

Логин (`username`) менять нельзя — он служит для входа и не меняется.

Чужой профиль открывается кнопкой **«Профиль»** в списке собеседников. Там видно роль
человека и его описание.

## Настройки приватности

Кнопка **«Настройки»**. Пять переключателей, для каждого три варианта:

| Настройка                   | Что регулирует                                     |
| --------------------------- | -------------------------------------------------- |
| Видимость профиля          | Кто может найти и открыть твой профиль             |
| Видимость онлайна          | Кто видит, что ты сейчас в сети                     |
| Личные сообщения           | Кто может начать с тобой переписку                  |
| Индикатор набора           | Кто видит, что ты печатаешь сообщение               |
| Отметки о прочтении         | Кому отправлять «прочитано»                        |

Уровни: **Все** (по умолчанию), **Только контакты**, **Никто**.

> «Только контакты» = те, с кем уже есть личная переписка. Отдельного списка
> контактов пока нет — если нужны именно заявки на добавление, скажи, добавлю.

Все настройки проверяются **на сервере**: скрытый профиль возвращает 403, запрещённые
личные сообщения не отправляются, скрытый онлайн не попадает в чужие списки. Скрыть
что-то в интерфейсе, не спрятав от сервера, невозможно.

## Роли

| Роль        | Права                                        |
| ----------- | -------------------------------------------- |
| Участник    | Только свой чат                               |
| Модератор   | + удалять любые сообщения                     |
| Админ       | + удалять людей, выдавать роли, чистить чаты |

Роль выдаётся выпадающим списком в админке. Роль владельца (`ADMIN_USER`) менять
нельзя, и его нельзя удалить — иначе можно потерять доступ к админке.

## Админка

Аккаунт владельца создаётся сам при первом запуске.

| Переменная   | По умолчанию | Что делает                |
| ------------ | ------------ | ------------------------- |
| `ADMIN_USER` | `p3w1`       | Логин владельца (всегда админ) |
| `ADMIN_PASS` | `228_1337`   | Пароль при первом запуске |

Войди под этим логином → открой **`/admin`**.

⚠️ **Задай `ADMIN_PASS` в настройках хостинга.** Если пароль остался в коде по умолчанию,
его увидит любой, кто откроет репозиторий на GitHub.

Защита от перехвата: аккаунт владельца создаётся сервером при старте, а не через
обычную регистрацию. Поэтому никто не сможет занять этот логин раньше тебя.

## Быстрый старт у себя

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```bash
npm install
npm start
```

Открой <http://localhost:3000>, зарегистрируйся — и пиши.

На Windows можно просто запустить **`start.bat`**.

## Настройки (переменные окружения)

| Переменная            | Что делает                                                        |
| --------------------- | ----------------------------------------------------------------- |
| `PORT`                | Порт сервера. На хостинге задаётся сам, локально — 3000            |
| `JWT_SECRET`          | Секрет для подписи сессий. На хостинге **обязательно задай сам**   |
| `INVITE_CODE`         | Если задан — регистрация только с этим кодом                      |
| `ADMIN_USER`          | Логин владельца (по умолчанию `p3w1`), у него всегда роль админа  |
| `ADMIN_PASS`          | Пароль владельца при первом запуске (по умолчанию `228_1337`)       |
| `GUEST_USER`          | Логин второго постоянного аккаунта (по умолчанию `lilac`)           |
| `GUEST_PASS`          | Его пароль (по умолчанию `123456`)                                   |
| `TURN_URLS`           | Адреса TURN через запятую — если нужно задать на хостинге            |
| `TURN_USERNAME`       | Логин TURN                                                             |
| `TURN_CREDENTIAL`     | Пароль TURN                                                           |
| `DATA_DIR`            | Папка с файлом данных (по умолчанию `./data`)                      |
| `DISABLE_RATE_LIMIT`  | `1` — отключить ограничения на вход и регистрацию                  |

Ограничения по умолчанию: **10 попыток входа за 10 минут** и **10 регистраций за час**
с одного адреса. Если все сидят за одним интернетом (например, мобильный оператор
раздаёт один IP), попроси друзей зарегистрироваться по очереди или включи
`INVITE_CODE`. Для локальных прогонов тестов ставь `DISABLE_RATE_LIMIT=1`.

Пример для PowerShell:

```powershell
$env:JWT_SECRET = "длинная-случайная-строка"
$env:INVITE_CODE = "код-для-друзей"
npm start
```

## Как залить на хостинг

Проект подходит под любой хостинг, где есть Node.js и WebSocket.

### Render (самый простой, есть бесплатный тариф)

1. Залей код на GitHub.
2. [dashboard.render.com](https://dashboard.render.com) → **New +** → **Web Service** → подключи репозиторий.
3. Поля:
   - Environment: `Node`
   - Build command: `npm install`
   - Start command: `npm start`
4. В **Environment** добавь `JWT_SECRET` (любая длинная случайная строка).
5. Deploy → получишь адрес вида `lilac-xxxx.onrender.com`.

Или одной кнопкой: в проекте лежит `render.yaml` — на Render работает **New → Blueprint**.

> ⚠️ На бесплатном тарифе Render сервис засыпает, если на него никто не заходил (~5 минут),
> а файлы на диске **не сохраняются** — сообщения пропадут после перезапуска.
> Для переписки с друзьями это обычно не критично, но история может обнулиться.
> Как сделать постоянное хранилище — в разделе ниже.

## Если нужна постоянная история сообщений

Файловое хранилище не переживает пересоздание контейнера. Два пути:

1. **Бесплатная Postgres БД** — [Neon](https://neon.tech) или [Supabase](https://supabase.com)
   дают бесплатную базу. Скажи — переделаю `lib/db.js` под `pg`, и данные будут вечными.
2. **Дисковое хранилище** — платное, например 1 ГБ от Render.

## Голосовые звонки

Кнопка **«Звонок»** появляется только в **личной переписке** — в группах и каналах
звонков нет.

Как работает: голос идёт **напрямую между браузерами** (WebRTC), сервер только
пересылает сигналы — сам разговор через него не проходит.

Панель звонка занимает **всю ширину переписки** и висит под шапкой, как в Дискорде.
Сообщения и поле ввода остаются на месте — во время разговора можно спокойно
читать и писать.

Внутри панели два экрана:

**Экран 1 — входящий звонок.** Маленькая аватарка, имя, надпись «входящий звонок…» и
две круглые кнопки с иконками: красная трубка (отклонить) и зелёная галочка (ответить).

**Экран 2 — разговор.** Пока никто ничего не показывает — две аватарки по центру:
собеседник и ты, у говорящего аватар обводится **сиреневым** и светится. Когда
соединились, под обоими именами идёт время разговора — сразу видно, что человек
подключился. Под аватарками — полоска уровня звука.

Кнопки во время разговора — три круглые, **без подписей**, как в Дискорде:
- 🎤 **микрофон** — заглушить себя (можно включить обратно). Заглушенный микрофон
  перечёркнут, а твой аватар гаснет
- 🖥 **демонстрация экрана** — горит сиреневым, когда идёт показ
- ✕ **завершить** — положить трубку, собеседник сразу увидит
- **Повторить** — если не соединилось, перезвонить ещё раз

Подсказка с названием всплывает при наведении. Иконки нарисованы прямо в коде
(SVG), эмодзи не используются — они выглядят по-разному в разных браузерах.

Если не отвечают 45 секунд — звонок сбрасывается сам. Если закрыть вкладку во время
разговора — второй человек тоже получит сброс. Если ты уже в звонке, а звонят ещё —
входящий сразу отклоняется.

При принятии звонка браузер спросит разрешение на микрофон. **Без HTTPS микрофон не
работает** — на Render как раз HTTPS.

### Демонстрация экрана

Кнопка **«Экран»** во время звонка. Браузер покажет своё стандартное окно выбора —
**весь экран**, **окно приложения** или **вкладка**. Выбрать можно любой: отдельное
своё окно выбора, как в Дискорде, браузер не даёт делать — это ограничение
безопасности самого браузера.

Что происходит:
- показы занимают **сцену слева**, а участники переезжают в колонку справа — как в Дискорде
- показывать могут **оба сразу**: одна плитка занимает всю сцену, две и больше встают рядом
- кнопка **⛶** в углу плитки разворачивает показ во весь экран; **Esc** возвращает как было
- кнопка «Экран» горит сиреневым и пишет «Стоп»
- если закрыть окно выбора, ничего не ломается — как будто не нажимали

Разворот работает всегда: сначала включается штатный полный экран браузера, а если он
запрещён (браузеры часто блокируют вызов из скрипта) — плитка растягивается поверх
страницы. Выглядит одинаково.

Полезно знать:
- **вкладку с самим Lilac** браузер не предложит — иначе был бы петля и человек
  увидел бы экран самого себя
- остановить демонстрацию можно и кнопкой в браузере («Остановить показ») — у второго
  человека видео пропадёт сразу
- звук с экрана не передаётся, только картинка

Видео идёт по тому же соединению, что и голос: при включении экрана браузеры заново
обмениваются настройками связи (это занимает долю секунды и разговора не прерывает).

### Если звонок не соединяется: «Прямое соединение невозможно»

Это **не ошибка в коде**, а особенность сети. Телефоны на разных провайдерах обычно
соединяются напрямую. Но если провайдер или мобильный оператор прячет твой адрес
(жёсткий NAT), прямой связи не будет ни при каких настройках.

Что сделать — два способа.

#### Способ 1: вручную в админке (сразу, просто)

На [dashboard.xirsys.com](https://dashboard.xirsys.com) → **Connect**:

1. В карточке **Channel** нажми **+**, введи имя канала (например `lilac`) → **Add**
2. Переключи **Channel Credentials** в режим **Static**
3. Появится блок с адресами, логином и паролем. Скопируй:
   - все строки `stun:` / `turn:` / `turns:` — **без кавычек** и без `"urls":`
   - `username` → поле **Логин**
   - `credential` → поле **Пароль**
4. В Lilac: войди как `p3w1` → `/admin` → **«TURN-сервер для звонков»** →
   вставь → **Сохранить**

Пример того, что вставлять — одна строка на один адрес:

```
stun:fr-turn1.xirsys.com
turn:fr-turn1.xirsys.com:3478?transport=udp
turn:fr-turn1.xirsys.com:80?transport=tcp
turns:fr-turn1.xirsys.com:5349?transport=tcp
```

⚠️ **Static-креды Xirsys даются только на 30 дней.** У тебя они действуют до
**6 ноября 2026**. После этого отключатся, и звонки перестанут соединяться — тогда
либо продли подписку, либо переходи на способ 2.

#### Способ 2: автоматически (без срока давности)

Сервер сам берёт временные креды по API Xirsys и обновляет их. Секрет остаётся на
сервере и в браузер не попадает.

На Render открой **Settings → Environment** и добавь:

| Ключ             | Значение                    |
| ---------------- | --------------------------- |
| `XIRSYS_IDENT`   | `ident` со страницы Xirsys  |
| `XIRSYS_SECRET`  | `secret` со страницы Xirsys |
| `XIRSYS_CHANNEL` | имя канала, например `lilac` |

После этого звонки будут работать, пока есть бесплатный тариф Xirsys.

⚠️ **Если Xirsys-секрет где-то засветился** — прислал в чат, попал в скриншот,
утёк в репозиторий — сразу нажми **renew** у API Key. Старый секрет перестанет
работать, а новый вставь в Render.

Как проверить, что TURN заработал: F12 → Console при звонке. Должны появиться
строки `[звонок] кандидат: srflx` (STUN сработал) и `[звонок] кандидат: relay`
(TURN заработал). Если только `host` — внешних адресов не нашлось.

⚠️ **TURN обязательно с логином и паролем.** Chrome падает с `InvalidAccessError`
на TURN с пустыми полями — звонки перестают работать вообще. Админка не даст
сохранить такие настройки. Только `stun:` можно без пароля.

#### Способ 3: ничего не настраивать (уже работает из коробки)

В коде есть **запасные бесплатные серверы** — Google STUN и Open Relay TURN. Они
подставляются автоматически, если Xirsys не настроен, ключ протух или его отклонили.
Твой адрес при этом никому не отдаётся: TURN просто пересылает голос.

Если в консоли браузера `[звонок] ice:` показывает `relay` — путь через TURN найден,
значит звонок соединится даже у тех, кто за жёстким NAT.

### Почему не соединяется: смотри консоль браузера

`F12` → Console. При неудачном звонке там будет:

| Сообщение | Что значит |
| --- | --- |
| `[звонок] не соединилось: {turnSource: …, host, srflx, relay}` | сводка: какой TURN использовался и сколько адресов нашлось |
| `[звонок] ice: checking` → `connected` | всё в порядке |
| `[звонок] ice: failed` | путь не найден совсем |

Если `srflx` и `relay` равны нулю — сеть не пускает наружу ни STUN, ни TURN: это
ограничение сети (часто мобильный оператор или корпоративный firewall), настройками
со стороны сайта это не лечится.

### Значки не появились после обновления

Статика отдаётся с `Cache-Control: no-cache`, так что браузер не должен держать старые
файлы. Если всё же видишь старое оформление — сделай жёсткую перезагрузку:
`Ctrl+Shift+R` (или `Ctrl+F5`). На телефоне — закрыть вкладку и открыть заново.

## Админка

Кнопка **«Админ»** в шапке чата — она есть только у админов и модераторов.
Обычные участники её не видят, а при прямом заходе на `/admin` сервер всё равно
не пустит — права проверяются на сервере, а не в интерфейсе.

Адреса:
- `/admin` — сама панель
- роли, статистика, удаление пользователей и сообщений, TURN — там же

В консоли браузера (F12 → Console) при звонке видно:
`[звонок] ice: checking` → `connected` или `failed`. Если `failed` — сеть не даёт
прямое соединение, нужен TURN.

## Группы и каналы

Кнопки **«+ Группа»** и **«+ Канал»** в боковой панели.

**Группа** — пишут все участники. **Канал** — пишут только владелец и помощники,
остальные читают (как в Telegram). Публичный канал читают все, кто зашёл на сайт.

Кнопка **ℹ** у группы или канала открывает настройки:
- переименовать, изменить описание (владелец и помощники)
- добавить участника по логину (владелец и помощники)
- назначить и снять помощника (только владелец)
- убрать участника (владелец и помощники)
- покинуть группу (владелец не может — сначала передай права или удали)

Защита от потери доступа: владельца нельзя убрать из группы, покинуть её или
понизить роль. Права проверяются на сервере — участник не может ни переименовать
группу, ни убрать кого-то, даже если подделает запрос.

В админке есть раздел «Группы и каналы» — можно удалить любую комнату.

## Тесты

```bash
npm start                  # в одном окне
DISABLE_RATE_LIMIT=1 npm start   # или так, если упираешься в лимиты
npm test                   # в другом
```

Семь наборов: `test/e2e.js` — регистрация, вход, чат; `test/admin.js` — права и
модерация; `test/features.js` — профиль, приватность, роли, прочтения;
`test/rooms.js` — группы и каналы; `test/calls.js` — сигналинг звонков;
`test/accounts.js` — постоянные аккаунты; `test/avatars.js` — аватарки.
Всего 138 проверок. Звук самих звонков и показ экрана тесты не проверяют — нужен браузер с микрофоном.

## Безопасность

- Пароли только в виде bcrypt-хэшей, в коде их нет
- Cookie `httpOnly` + `SameSite=Lax`, на HTTPS ещё и `Secure`
- Ограничение попыток входа: 10 за 10 минут с одного IP
- Все сообщения вставляются через `textContent` — HTML и скрипты не выполняются
- Аватар принимается только как `data:image/...` — картинкой отдаётся отдельным
  запросом, а в списках людей лежит лишь флаг «аватар есть», чтобы списки не раздувались
- Доступ к личной переписке проверяется на сервере по ID пользователя
