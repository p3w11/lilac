# Волна

Локальный музыкальный плеер с русским интерфейсом. Ищет песни, альбомы и исполнителей, собирает очередь, запоминает избранное и историю. Полные песни играются через официальный YouTube IFrame Player API — музыка не скачивается на диск.

## Быстрый запуск

1. Установите Python 3.8 или новее (при установке отметьте «Add Python to PATH»).
2. Дважды щёлкните `Запустить.bat`.
3. Откроется браузер с адресом <http://localhost:8787/>.

Окно с сервером должно оставаться открытым: закройте его, чтобы остановить сайт.

Если браузер открылся слишком рано и показывает ошибку соединения, просто обновите страницу.

Запуск вручную:

```bash
cd volna
python server.py
```

После запуска откройте <http://localhost:8787/>. Порт можно изменить переменной окружения `VOLNA_PORT`, например:

```powershell
$env:VOLNA_PORT=9000; python server.py
```

## Зачем нужен server.py

Это не просто раздача статических файлов. `server.py` поднимает локальный HTTP-сервер и проксирует поиск YouTube Music / YouTube:

- `GET /api/yt/search?q=Кино&limit=24` — поиск треков;
- `GET /api/health` — проверка, что сервер жив.

Прокси нужен, потому что браузер не может напрямую запросить страницу поиска YouTube из-за CORS. Аудио и видео при этом воспроизводит официальный встроенный плеер YouTube, а не сам сервер.

## Источники музыки

| Источник | Что даёт |
| --- | --- |
| YouTube | Полные треки и клипы, бейдж «полный». Основной источник. |
| iTunes | Метаданные, обложки, 30-секундные превью. |
| Deezer | Метаданные, обложки, 30-секундные превью. |
| Мои файлы | Локальные аудиофайлы с диска. |

По умолчанию выбран источник **YouTube**, поэтому результаты поиска состоят из полных песен. Переключатель «Всё» объединяет YouTube с iTunes и Deezer: полные версии имеют приоритет, но для редких песен могут остаться 30-секундные превью.

Для поиска исполнителя YouTube-прокси дополнительно запрашивает популярные песни, чтобы выдача не ограничивалась 10–15 треками.

## Возможности

- Главная страница, «Волна дня», подборки по настроению.
- Поиск по трекам, альбомам и исполнителям.
- Фильтры выдачи: всё, треки, альбомы, исполнители.
- Очередь: добавление, удаление, перемешивание, очистка, переход к текущему треку.
- Избранное и история прослушиваний.
- Локальные файлы: выбор через проводник или перетаскивание в окно.
- Плеер: play/pause, перемотка, громкость, mute, следующий/предыдущий, повтор, shuffle.
- Визуализатор для локальных файлов и аудио iTunes/Deezer; для YouTube используется скрытый iframe-плеер.
- Светлая и тёмная темы.
- Адаптивная вёрстка и мобильное меню.
- Горячие клавиши.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Space` | Воспроизведение / пауза |
| `←` / `→` | Перемотка на 5 секунд |
| `Shift` + `←` / `→` | Предыдущий / следующий трек |
| `↑` / `↓` | Громкость |
| `M` | Выключить / включить звук |
| `L` | Добавить текущий трек в избранное |
| `S` | Перемешивание |
| `Q` | Очередь |
| `/` или `Ctrl+K` | Перейти к поиску |
| `?` | Справка по клавишам |
| `Esc` | Закрыть панель или очистить поиск |

## Структура проекта

```text
volna/
├─ index.html          # разметка приложения
├─ server.py           # локальный сервер и прокси поиска YouTube
├─ Запустить.bat       # запуск в один клик
├─ css/app.css         # стили и адаптивность
└─ js/
   ├─ util.js          # утилиты и форматирование
   ├─ store.js         # localStorage: избранное, история, очередь, настройки
   ├─ youtube.js       # поиск YouTube и IFrame Player API
   ├─ api.js           # iTunes, Deezer, YouTube, объединение и дедупликация
   ├─ id3.js           # чтение тегов локальных файлов
   ├─ library.js       # локальная библиотека файлов
   ├─ player.js        # плеер, очередь, состояние, горячие клавиши
   ├─ ui.js            # шаблоны экранов и карточек
   └─ app.js           # роутер и связывание модулей
```

## Важно знать

- Нужен интернет: без него останутся только локальные файлы.
- YouTube может ограничивать автовоспроизведение. Плеер стартует в беззвучном режиме и включает звук после загрузки; если браузер всё равно блокирует запуск, нажмите кнопку воспроизведения ещё раз.
- iTunes и Deezer отдают только 30-секундные превью. Полные версии этих треков ищутся на YouTube.
- Приложение не скачивает музыку и не обходит ограничения сервисов: YouTube-треки играются через официальный встроенный плеер.
- Данные (избранное, история, очередь, тема, громкость) хранятся в `localStorage` браузера. Очистка данных сайта сбросит настройки.
- Для работы YouTube IFrame API требуется доступ к `youtube.com` и `ytimg.com`.
